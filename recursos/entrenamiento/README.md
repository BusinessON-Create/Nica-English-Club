Build the idea. Move it through time. Say it out loud.

Students pick a subject and a verb (or type their own), "season" the sentence with what / how / where / with whom / when / a second idea, and the engine fills all 12 tenses plus *going to*, with audio, Listen & Repeat and Build-up pronunciation practice.

## Run
Open `index.html`, or publish with **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Stack
Tailwind CSS · Lucide Icons · AOS · canvas-confetti · Google Fonts · Web Speech API (no backend, no saving, no AI).
